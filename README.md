# ⛽ متابعة بطاقة الوقود — ALSCIF

تطبيق ويب خفيف (PWA) لمتابعة استهلاك بطاقة الوقود (Fiche de suivi). يخدم **بدون انترنت**، وتتثبت على التليفون كتطبيق. البيانات تتخزن ف الجهاز نفسه (localStorage)، ما تتبعثش لأي سيرفر.

## المميزات
- تسجيل الوصولات: التاريخ، السائق، المركبة، المبلغ، رصيد الوصل — الكمية تتحسب أوتوماتيكيا (**31 دج / لتر**)
- إنذار لما رصيد الوصل ينقص عن الرصيد المتوقع (كشف التلاعب)
- تعديل وحذف أي عملية
- `Type d'Engin ou véhicule` و `Immatriculation` قابلين للتعديل
- **دورة الشحن:** تنبيه لما الرصيد يوصل لحد معين ← تصوير آخر وصل ← الإدارة تشحن ← تسجيل مبلغ الشحن
- تصوير آخر وصل (كاميرا أو معرض) ← يطلع ف **الصفحة الثانية** من الـ PDF
- **3 لغات:** عربية / Français / English (زر ف الأعلى، الاختيار يتحفظ، والواجهة تتقلب RTL/LTR أوتوماتيكيا)
- تصدير **PDF بصيغة A4** (Fiche de suivi) و **Excel**

## التشغيل
افتح `index.html` مباشرة ف المتصفح، ولا:
```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

## النشر على GitHub Pages
1. دير repository جديد ف GitHub وارفع كامل الملفات.
2. `Settings → Pages → Build and deployment → Deploy from a branch`
3. اختار `main` و `/ (root)` ثم Save.
4. الرابط يطلع ف دقيقة: `https://USERNAME.github.io/REPO/`
5. ف التليفون افتح الرابط ← "إضافة إلى الشاشة الرئيسية" باش يتثبت كتطبيق.

## 📱 تحميل APK مباشرة من GitHub
الـ APK يتبنى أوتوماتيكيا ب GitHub Actions (Capacitor) كل ما ترفع تعديل على `main`:
1. ارفع الملفات (بما فيهم مجلد `.github`) على GitHub.
2. ادخل تبويب **Actions** ← **Build Android APK**، استنى 5-10 دقايق حتى يولي أخضر ✅ (تقدر تشغله يدويا بـ "Run workflow").
3. ادخل **Releases** (ف يمين صفحة الريبو) ← حمّل `ALSCIF-Carburant.apk`.
   الرابط الدايم لآخر نسخة: `https://github.com/USERNAME/REPO/releases/latest`
4. ف التليفون: افتح الملف وثبّتو (فعّل "السماح بالتثبيت من هذا المصدر" إذا طلبها).

ملاحظات:
- إذا فشل النشر ف Releases: `Settings → Actions → General → Workflow permissions → Read and write permissions`.
- الـ APK موقّع بمفتاح debug (يخدم للتثبيت المباشر، ماشي للنشر ف Google Play).
- **PDF** ف التطبيق يفتح نافذة الطباعة تاع الأندرويد (A4)، اختار "Save as PDF". **Excel** يتبعث عبر المشاركة (Share) باش تحفظه ولا تبعثه.
- ملفات المشروع الخاصة بالـ APK: `.github/workflows/build-apk.yml`, `capacitor.config.json`, `package.json`, `android-overrides/`, `scripts/`, `assets/`.

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | هيكل الصفحة ومنطقة الطباعة |
| `style.css` | التصميم + تنسيق الطباعة A4 |
| `app.js` | المنطق (الحسابات، الشحن، الصور، التصدير) |
| `i18n.js` | نصوص اللغات الثلاث (باش تزيد لغة: زيد قاموس جديد هنا) |
| `manifest.webmanifest`, `sw.js`, `icons/` | التثبيت كتطبيق والعمل بلا انترنت |

## ملاحظات
- نموذج الـ PDF وملف Excel يبقاو بالفرنسية (Fiche de suivi الرسمية) مهما كانت لغة الواجهة.
- البيانات مرتبطة بالمتصفح والجهاز: ما تتنقلش بين جهازين. صدّر Excel كنسخة احتياطية.
- لما تبدل ملفات التطبيق بعد النشر، زيد رقم النسخة في `sw.js` (`CACHE`) باش المتصفح يحدّث.
